# GLOSSARIO.md – Termos da técnica Fimathe

Termos extraídos do Doc A e do relatório de requisitos (Doc B).
Quando houver divergência entre fontes, a origem é indicada.

| Termo | Definição (fiel às fontes) | Fonte | Clareza |
|-------|---------------------------|-------|--------|
| **Ponto A / Ponto B** | Níveis de suporte e resistência da consolidação. Região entre eles = máxima da exaustão. | Doc A | Média |
| **Canal** | Intervalo entre A e B (ou entre máxima/mínima do CA). Usado de forma operacional. | Doc A + Doc B | Média |
| **Máxima da exaustão** | Região entre A e B onde o preço perde força. | Doc A | Média |
| **Expansão** | Projeção da altura do canal (A-B) no sentido da tendência. | Doc A | Alta |
| **50% / 100%** | Níveis de correção e agrupamento mais importantes. | Doc A | Alta |
| **Agrupamento** | Consolidação nas máximas de exaustão e nos 50%. | Doc A | Baixa (subjetivo) |
| **Pullback** | Movimento de correção após atingir a expansão. | Doc A | Alta |
| **Triângulo de 100% Fibonacci** | Formação após queda de 2 níveis; perda autoriza venda em alta. | Doc A | Baixa |
| **0x0** | Região inicial da projeção (Doc A) ou preço de entrada/breakeven (Doc B). | Ambos | Ambígua |
| **Canal de Abertura (CA)** | Máx/mín das 4 primeiras velas M15 após abertura de domingo (Brasília). | Doc B §3.2 | Alta/Baixa |
| **C1, C2, C3, C4** | Ciclos projetados a partir do CA. Fórmula ainda ambígua. | Doc B §3 | Baixa |
| **Zona Neutra** | Canal imediatamente anterior/oposto ao de Referência. | Doc B §2.2 | Média |
| **Canal de Referência** | Máx/mín de um “período relevante”. | Doc B §2.1 | Baixa |
| **Linha de Equador** | Linha no gráfico semanal que divide compradores/vendedores. | Doc B §2.3 | Baixa |
| **Virada de mão** | Após stop, fechamento além do ciclo anterior no sentido oposto. | Doc B §5 | Média |
| **PCM** | Após take/stop, aguarda 4 velas, traça novo CA e opera o rompimento. | Doc B §6 | Média |
| **Fatiamento** | Quando a altura do CA ultrapassa certo número de pontos, o canal é dividido. | Comunidade | Não formalizado |
| **Surfar** | Avançar o stop a cada 50% de subciclo / 100% de nível. | Doc A + Doc B | Alta |
| **Caixinha** | Stop além da Zona Neutra ou dentro do CA. | Doc B | Média |

**Notas:** Termos com clareza “Baixa” ou “Ambígua” não devem ser implementados de forma rígida até esclarecimento.
